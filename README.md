# My Todo List

Une mini-application de gestion des tâches construite avec HTML, CSS et JavaScript, sans framework ni dépendance externe.

## Fonctionnalités

- Ajouter une tâche.
- Marquer une tâche comme terminée ou à faire.
- Supprimer une tâche.
- Effacer toutes les tâches terminées.
- Afficher le nombre total de tâches, de tâches terminées et de tâches restantes.
- Enregistrer les tâches dans `localStorage` pour les retrouver après actualisation.
- Interface responsive pour ordinateur et téléphone.

## Lancer le projet

Aucune installation n'est nécessaire.

1. Télécharge ou clone le dépôt.
2. Ouvre `index.html` dans un navigateur.

## Déployer avec GitHub Pages

1. Envoie les fichiers du projet dans un dépôt GitHub.
2. Dans le dépôt, ouvre **Settings**.
3. Va dans **Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne la branche `main` et le dossier `/ (root)`, puis clique sur **Save**.
6. Attends la fin du déploiement. GitHub affichera l'URL publique du site dans la section Pages.

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)
- localStorage

## Fichiers

- `index.html` : structure de la page.
- `style.css` : présentation et adaptation aux écrans.
- `script.js` : gestion des tâches et stockage local.
- `spec.md` : courte spécification du projet.

## Données et confidentialité

Les tâches sont enregistrées localement dans le navigateur de l'utilisateur. Elles ne sont pas envoyées à un serveur.
